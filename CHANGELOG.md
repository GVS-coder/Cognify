# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-30
### Added
- **Authentication**: Integrated Firebase Auth with email/password and anonymous login.
- **Dashboard**: High-level overview of tasks, knowledge base items, and AI suggestions.
- **Task Management**: Create, edit, delete, and filter tasks. Added priorities and due dates.
- **Knowledge Vault**: Note-taking capability with markdown-like organization.
- **Calendar & Reminders**: View tasks in a monthly calendar view and set local reminders via WorkManager.
- **AI Assistant**: Integrated Gemini Pro API for context-aware chat, task generation, and studying insights.
- **Productivity Analytics**: Visual representations of completed tasks, streaks, and knowledge base additions.
- **Profile & Settings**: Manage display names, local profile photos, dark mode, dynamic colors, and AI preferences.
- **Export & Backup**: PDF/CSV generation for local exports, and manual Firestore sync capabilities.
- **Offline-First Support**: Room database as the single source of truth, with seamless background Firestore sync.
